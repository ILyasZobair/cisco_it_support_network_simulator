Lab 1: Active Directory & DNS Resolution Fail

Target Device: PC1 (Windows Client Terminal)

Ticket Description:

User on PC1 reports they cannot log in using domain credentials (USER@school.local). Executing `nslookup school.local` fails with DNS server unavailable. Fix the DNS address setting on PC1 to point to DC1 Server (192.168.40.10).

Recommended Solution Steps:

  1. Click on PC1 device in topology to open Windows Command Prompt.
  2. Check current config using ipconfig /all.
  3. Set correct DNS IP using command: netsh int ip set dns static 192.168.40.10.
  4. Test DNS using nslookup school.local.
